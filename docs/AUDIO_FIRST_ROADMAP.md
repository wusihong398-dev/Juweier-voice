# 橘味儿配音：音频优先开发路线

## 第一阶段：音频主产品

目标：把“导入短剧/音频 → 分离 → 换声 → 环境音还原 → 成品导出”做成普通用户也能一键完成的流程。

### 首页优先入口

1. AI短剧配音
2. 导入语音/视频换声
3. 对白 / BGM / 环境音分离
4. AI演员库（Voice ID）
5. AI声音设计
6. 项目中心 / 批量处理

所有声音入口统一支持常见音频和视频文件。前端不要求用户自行转换 WAV；由服务端使用 FFmpeg 统一转为模型内部格式。

## 一键短剧配音标准流程

1. 导入短剧视频或音频
2. 媒体分析与音轨提取
3. Roformer 分离对白、背景音乐与环境/音效
4. 人物/说话人识别与分段
5. 用户可手动修改人物与目标 Voice ID
6. Seed-VC V2 换声
7. 保留原对白时序与表演
8. 将换声对白与原 BGM / 环境音重新混合
9. 原视频画面直接回写，尽量避免重新编码画面
10. 导出成品 MP4 / 音频

## 建议统一 API

- `POST /api/v1/media/analyze`
- `POST /api/v1/separation`
- `POST /api/v1/vc/convert`
- `POST /api/v1/mix`
- `POST /api/v1/video/remux`
- `POST /api/v1/dubbing/project`
- `GET /api/v1/tasks/{task_id}`

Windows、Android、iOS 共用同一套服务端接口；模型升级时尽量不改三端客户端协议。

## iPhone 导入体验

优先级：

1. 从“照片”直接选择视频作为声音素材
2. 从“文件”导入音频或视频
3. App 内直接录音
4. 从微信、QQ、邮件等通过系统分享导入
5. 从 AI 演员库直接选择已经保存的 Voice ID

## 视频生成：开发测试中

LTX-Video 本地生成链路保留，不删除现有代码与模型。客户端不作为首页核心入口，放在“实验功能 / AI视频”区域。

客户端文案：

> AI 视频 · 开发测试中  
> 本地 AI 视频生成能力正在持续开发和优化。目前可用于体验测试，生成速度、画质与稳定性仍在改善，暂不建议用于正式生产项目。

当前阶段只保留文生视频、图生视频等实验入口；后续硬件、模型速度与长视频连续性成熟后再提升为正式功能。

## 开发优先级

P0：Seed-VC 换声稳定性、媒体格式兼容、文件导入体验  
P0：Roformer 对白/环境音分离 + 自动混回  
P0：原视频回写与成品导出  
P1：短剧项目、角色管理、Voice ID 与手动纠错  
P1：批量任务、进度、失败重试、历史结果  
P1：录音、iOS 相册/文件/分享导入  
P2：方言库、用户投稿与地区投票机制  
P3：本地 AI 视频生成正式化
